# Forum Backend

A backend for a discussion forum with nested comments and user profiles.

## Features

*   User Authentication (JWT)
*   User Profiles
*   Forums
*   Threads
*   Nested Comments

## Technologies

*   Node.js
*   Express.js
*   MongoDB
*   Mongoose
*   JSON Web Tokens (JWT)
*   bcrypt

## Installation

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Configure environment variables (see `.env.example`).
4.  Start the server: `npm start`
